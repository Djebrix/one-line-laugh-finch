## The line

> My therapist asked about my childhood. I showed her my git blame.

## How it works

`main.py` (Python 3, stdlib only) writes that single line to `/output/entry.txt`
(or `$ENTRY_OUTPUT_DIR/entry.txt` when set). The output is 65 characters —
inside the 1–200 character gate — and byte-identical on every run.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
